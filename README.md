# Dre After Dark · Life OS

A dark-academia, offline-first personal executive-function and habit-building PWA with household operations, Conservatory plant journals, analytics, reports, backup/export, and Supabase cloud sync.

## Hosting
This repository is intended for GitHub Pages from the `main` branch root.

## Privacy
The static application shell is public when hosted on GitHub Pages. Personal cloud records belong in Supabase and are protected by authentication and row-level security. Do not hard-code private journal content into this repository.

## Install
After GitHub Pages is enabled, open the HTTPS Pages URL in Chrome and choose **Install app** / **Add to Home screen**.
